# BBVA Bivi — Sitio

Sitio estático (HTML/CSS/JS) con landing pages para la cuenta Bivi de BBVA.

## Páginas

- `index.html` — Home
- `beneficios.html` — Beneficios
- `planes.html` — Planes
- `bivi.html` — Conoce a Bivi
- `login.html` — Acceso clientes
- `abrir-cuenta.html` / `abrir-cuenta-flow.html` — Apertura de cuenta
- `descargar-app.html` — Descarga de la app

## Estructura

```
css/       estilos (styles.css, wizard.css)
js/        comportamiento del sitio (main.js, bivi.js, wizard.js)
assets/    imágenes
```

## Cómo verlo localmente

Abrí `index.html` en el navegador, o levantá un servidor simple:

```bash
python3 -m http.server 8000
```

y entrá a `http://localhost:8000`.
